# v1.5.1 — English UI release

- Publish the validated English interface with a frozen CLIP column and resizable configuration matrix.
- Provide a minimal ZIP: the MIDI device, four required JavaScript files and installation instructions.
- Add English usage, development and validation documentation.
- Preserve the validated V1.5-EN runtime, interface, dependency paths and saved-state format byte for byte.

The project author validated the runtime in Ableton Live 12 with Push 2. Release preparation reran 45 automated tests and checked the native MIDI container, dependencies, clean ZIP extraction and saved-state compatibility. Previous native Max results are retained as historical evidence; no new hardware test is claimed.

Requires Live 12 with Max for Live and Max 9. Push playing layouts remain manual. No license terms are granted by this release; licensing will be decided separately.
